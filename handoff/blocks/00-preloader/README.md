# 00 · Прелоадер главной BARN Estate

[Превью](index.html) · [HTML](../../html/00-preloader.html) · [CSS](../../css/00-preloader.css) · [JS](../../js/00-preloader.js) · [Готовая вставка](../../paste.html)

`00-preloader.html` содержит только компонент, без body/main/layout и без следующего экрана. Логотип встроен в HTML как data URI; его исходный SVG лежит в assets. CSS и JS не требуют общей библиотеки блоков, Nuxt, Vue, React или npm-пакетов. Фото в CSS подключается относительно файла стилей из ../../assets/.

Вставляй в начале body на главной, вне корня Nuxt/Vue. Подключи CSS в head и JS сразу после фрагмента; не используй async/defer. Полная схема — [INTEGRATION.md](../../INTEGRATION.md). На странице должен быть только один экземпляр. После анимации узел удаляется и открывается уже существующая страница. В отдельном превью остаётся пустой белый фон.
