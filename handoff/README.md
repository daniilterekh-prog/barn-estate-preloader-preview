# BARN Estate — прелоадер для разработчика

[Каталог](index.html) · [Превью блока](blocks/00-preloader/index.html) · [Интеграция](INTEGRATION.md) · [ZIP](barn-estate-preloader.zip)

Один блок 00-preloader. Формат как в handoff/current: отдельные html/css/js/assets и описание с метаданными в blocks/. Версия компонента1.0.0, упаковка09.11.2026. После прелоадера нет демонстрационного hero, кнопок или другой страницы. Рабочая главная при установке остаётся под прелоадером.

| Что передать | Файл |
|---|---|
| HTML компонента | html/00-preloader.html |
| Оформление и анимация | css/00-preloader.css |
| Запуск и завершение | js/00-preloader.js |
| Фото и исходный логотип | assets/ |
| Чистое превью и описание блока | blocks/00-preloader/ |
| Минимальная HTML-оболочка | html/page-shell.html |
| Сборная вставка | paste.html |
| Происхождение и SHA-256 | SOURCE.json |

Рекомендуемый перенос — отдельные файлы с локальными ассетами. paste.html включает HTML/CSS/JS и логотип, но использует публичный URL фото: это готовая альтернативная вставка. Два способа не подключать одновременно.

Для локального просмотра: python3 -m http.server 8080 из распакованной папки; открыть /blocks/00-preloader/. Код не требует сервера приложений. На боевой barn-estate.ru не установлен.
