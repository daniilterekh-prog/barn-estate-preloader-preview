# Подключение 00-preloader

## Отдельные файлы — рекомендуемый вариант

1. Размести css/, js/ и assets/ из комплекта в /preloader/ целевого сайта, сохранив структуру.
2. В head главной добавь `<link rel="stylesheet" href="/preloader/css/00-preloader.css">` до первого показа страницы. Фото в CSS найдётся по ../assets/home-hero-cleaned.png.
3. Сразу после открывающего body вставь содержимое html/00-preloader.html. Это фрагмент, без собственной оболочки страницы. Логотип уже встроен в img как data URI.
4. Сразу после фрагмента вставь `<script src="/preloader/js/00-preloader.js"></script>`. Скрипт должен запускаться здесь, без async/defer и без ожидания общей клиентской сборки. Регистрация таймера происходит до показа слоя.
5. Ниже остаётся существующая главная сайта. Демонстрационного экрана в комплекте нет. В Nuxt/Vue размести прелоадер вне #__nuxt, чтобы гидратация его не пересоздавала; подключай только в серверном документе главной и один раз. Это стартовая анимация полной загрузки, не переходов между SPA-маршрутами.

html/page-shell.html — минимальный исполняемый пример. При строгой CSP разреши локальный JS/CSS, data: для логотипа и источник фото; для варианта paste.html примени принятый на проекте nonce/hash к inline style/script.

## Готовая вставка

paste.html содержит только style + компонент + script. Вставь его сразу после открывающего body вне корня приложения. Не добавляй его вместе с отдельными файлами. Фото использует https://daniilterekh-prog.github.io/barn-estate-homepage-clone/exact-2026-10-21/assets/home-hero-cleaned.png; для независимости от внешнего хостинга замени этот адрес на локальное фото из assets/.

## Параметры и поведение

- Экран fixed/inset0, ширина100vw, z-index2147483647; стили изолированы префиксом be-preloader. Подложка #111 и затемнение rgba(13,13,13,.84).
- Контент: min(560px,100vw−48px). Логотип256px, на экране до640px —216px; пропорции SVG327×91,11 сохранены. На узких экранах подписи идут вертикально. Текст: Tilda Sans сайта, fallback Arial,11px, line-height1.2, letter-spacing.14em, uppercase.
- Линия1px, отступ38px от логотипа, подписи через22px. Заполнение —1550ms с задержкой350ms. Это декоративная анимация, не процент загрузки.
- При быстрой загрузке выход начинается через1900ms от запуска скрипта; при долгой —через3500ms независимо от window.load. Выход вверх900ms, DOM-узел удаляется через950ms после начала выхода.
- Без JS слой по умолчанию скрыт. При prefers-reduced-motion он сразу удаляется; включение этой настройки во время показа также удаляет его. Дополнительное CSS-скрытие через5s страхует сбой JS после показа.
- Обработка pageshow с persisted=true убирает слой при восстановлении bfcache. Скрипт не меняет фокус, overflow страницы, scroll position, историю или маршруты. Колесо/свайп на самом видимом слое подавляются.
- Никаких API, форм, трекинга и сторонних библиотек. Подключай существующий Tilda Sans сайта отдельно; новые шрифты в пакет не добавлены.

## Приёмка

Проверь390/768/1440/2560px: логотип по центру, нет переполнения, после выхода видна исходная главная. Проверь медленное фото, отключённый JS, reduced motion и возврат назад. В standalone-превью после удаления слоя остаётся пустой фон, это ожидаемо. Не переносить index.html каталога в разметку сайта — он служит только для передачи файлов.
